# Babylon.js WebGPU shader tools

The files in `9.33.0/` are copied without modification from the matching
[Babylon.js 9.33.0 release](https://github.com/BabylonJS/Babylon.js/tree/9.33.0/packages/tools/babylonServer/public).
They provide the GLSLang and Tint/WGSL compiler runtime used by Babylon.js.
Runtime URLs point here so the gallery does not require a shader-tool CDN.
Update these files and the versioned URL in `src/renderer.js` together when upgrading Babylon.js.
